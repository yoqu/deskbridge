# DeskBridge 技术支持 / Support

## 中文

**联系我们**：yoqulin@gmail.com（通常 2 个工作日内回复）

**常见问题**

- **找不到另一台 Mac**：两台 Mac 都要安装并打开 DeskBridge，并处于同一局域网，或用雷电线、网线直连。请在「系统设置 › 隐私与安全性 › 本地网络」中允许 DeskBridge。
- **鼠标过不去 / 键盘没反应**：两台 Mac 都要在「系统设置 › 隐私与安全性 › 辅助功能」中允许 DeskBridge。
- **和系统自带功能冲突**：在「系统设置 › 显示器 › 高级」中关闭「允许指针和键盘在附近任何 Mac 或 iPad 之间移动」。
- **随时收回控制**：按 ⌃ Control + ⌥ Option + ⌘ Command + Esc。
- **重新配对**：指向面板顶部两台 Mac 之间的连接线，点击后确认取消配对，再重新配对。

## English

**Contact**: yoqulin@gmail.com (we usually reply within 2 business days)

**FAQ**

- **The other Mac doesn't show up**: install and open DeskBridge on both Macs, on the same local network or linked by a Thunderbolt or Ethernet cable. Allow DeskBridge under System Settings › Privacy & Security › Local Network.
- **The pointer won't cross / keys don't arrive**: allow DeskBridge under System Settings › Privacy & Security › Accessibility on both Macs.
- **Conflicts with the built-in feature**: turn off "Allow your pointer and keyboard to move between any nearby Mac or iPad" in System Settings › Displays › Advanced.
- **Take control back at any time**: press ⌃ Control + ⌥ Option + ⌘ Command + Esc.
- **Pair again**: point at the link between the two Macs at the top of the panel, click it and confirm to unpair, then pair again.
